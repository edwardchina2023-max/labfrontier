# 实验室前线 / LAB FRONTIER

实验室前线是“前沿科技发现与价值转化媒体”。网站以品牌母稿、旗舰深稿、品牌影片脚本、20 个实验室故事和既有视觉原画为内容基础，沿着“新闻 → 公司 → 技术 → 论文 → 科学家 → 实验室”回到科技发生的源头。

品牌使命：去源头。见真人。把未来讲明白。

品牌 Slogan：梦开始的地方 / Where the future begins.

## 网站内容

- 旗舰深稿：《当实验室开始像计算机一样运行》等三个已确认选题
- 六个内容世界：实验室现场、实验室里的人、前沿、从实验室到市场、改变世界的实验室、思想实验室
- 黄师傅 / Edward Huang 与实验室前线的双层品牌结构
- 内容溯源方法、信源分级与每日编辑工作流
- 第一季 20 个实验室故事及口播脚本摘要
- 75 秒品牌母片《未来还没有名字的时候》完整分镜
- 36 张科学家与科技里程碑概念原画档案

概念原画仅用于品牌视觉研究。正式商业发布前，应逐张替换为确认授权、公版或自行拍摄的真实影像。

## 本地运行

```bash
npm install
npm run dev
```

生产构建与测试：

```bash
npm run build
npm run test:sites
```

## 发布

推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。

## 视觉方向

网站采用 “Frontier Observatory / 前沿观测站” 方向：深海军蓝、信号青、真实实验室影像与克制的双语编辑设计。设计目标和验收记录见 [design-qa.md](design-qa.md)。
