# 实验室前线 / LAB FRONTIER

实验室前线官网，以“从实验室出发，抵达未来”为核心叙事，连接世界前沿实验室、代表性科学家、技术里程碑与正在发生的科研现场。

## 网站体验

- 沉浸式实验室影像首页与双语品牌系统
- 前沿研究、科学家、科技史、现场四条内容主线
- 全站搜索、内容预览与邮件订阅交互
- 桌面端与移动端响应式布局
- 键盘焦点、减少动态效果等无障碍适配

## 本地运行

```bash
npm install
npm run dev
```

生产构建与测试：

```bash
npm run build
npm run test:sites
```

## 发布

推送到 `main` 分支后，GitHub Actions 会自动构建并发布到 GitHub Pages。

## 视觉方向

网站采用 “Frontier Observatory / 前沿观测站” 方向：深海军蓝、信号青、纪实实验室摄影、克制的双语编辑设计。设计目标与视觉验收记录见 [design-qa.md](design-qa.md)。
